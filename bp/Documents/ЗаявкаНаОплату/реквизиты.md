# Реквизиты живой `ФУ_ЗаявкаНаОплату`

Снято с формы документа и модуля объекта. Писать в заявку только эти поля.

## Шапка

| Реквизит | Как в форме |
|----------|-------------|
| Организация | `ВыводОрганизацияПоУмолчанию()` |
| Статус | `Создана` → `НаСогласовании` → `Одобрена` → `ЧастичноОплачена` / `Оплачена` / `Отклонена` |
| ФормаОплаты | `Безналичная` |
| ОтветственныйОплаты | текущий пользователь |
| Валюта | `643` |
| Тема | тема / заголовок из ДО |
| Назначение | назначение платежа из ДО (`Назначение` / `НазначениеПлатежа`) |
| Сумма, СуммаОдобрено, СуммаОплачено, СуммаВозвращено | числа |
| ПланируемаяДатаОплаты | дата первой строки графика |
| ПланируемаяДатаОпл | строка дат `дд.ММ.гггг, …` (пишет форма при записи) |
| ДатаОдобрения | при статусе Одобрена |
| НомерСчетаДО, ДатаСчетаДО | связь с ДО |
| Контрагент, Договор, ФизЛицо | |
| СтатьяДвиженияДС, СтатьяЗатрат | статья затрат из `ФУ_СвязьСтатейДДСиЗатрат` |
| СверхлимитнаяЗаявка | булево |
| Фонд, ФондОтбор | фонд из `ФУ_СвязиСтатейИФондов`; запись без галочки ФондОтбор требует связку |
| ПлановаяЗаявка | булево |
| СсылкаНаПлановуюЗаявку | у заявки из счёта ДО, созданного из плановой — ссылка на плановую заявку БП |
| ДокументОснование | дубль связи с плановой, если реквизит ещё пишется |
| Служебная | |

## ТЧ `ГрафикПлатежей`

`ДатаПлатежа`, `СуммаКОплате`, `Статус` (булево одобрения строки — галка в графике), `ДатаПлатежаФакт`, `ПлатежноеПоручение`, `ПлатежныйДокумент`.

При статусе заявки **Одобрена** все строки графика должны быть с `Статус = Истина`, иначе «Остаток к согласованию» не обнуляется. Колонки `Согласовано` в живой ТЧ нет.

## ТЧ `Согласующие`

`ДолжностьСогласующего` (в форме сравнивают как строку), `Согласовано`.

Заполнять через `ФУ_ОбщийМодульСервер.ЗаполнитьСогласующих(ЗаявкаНаОплату, Дата, Ссылка)`.

## Куда не класть код

- `ПриЗаписи.bsl` объекта — только в модуль объекта.
- `ОтправкаСтатусаВДО.bsl` — только в расширение формы заявки.
