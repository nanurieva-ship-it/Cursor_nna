# Cursor + 1С (ДЕПО)

Материалы из работы в Cursor: контекст агента, скрипт автообновления типовой на поддержке, схемы MCP/CFU, модуль графика платежей.

Учётная запись GitHub: [nanurieva-ship-it](https://github.com/nanurieva-ship-it).

## Состав

| Файл | Назначение |
|---|---|
| `AGENTS.md` | Контекст агента: MCP depo_copy2, фонды, подписка поступлений |
| `update_1c_universal.ps1` | Автообновление CFU на `192.168.80.15` |
| `ФУ_ЗаявкаНаОплату_ЗаполнениеГрафикаПлатежей.bsl` | Заполнение ТЧ `ГрафикПлатежей` |
| `как-ии-обновил-1с.html` | Схема автообновления для программистов 1С |
| `схема-обновления-1с.html` | Тайминги прогона БП/ЗУП |
| `схема-mcp-vs-odata.html` | Почему код пишем через MCP, не OData |
| `презентация-mcp-код-1с.html` | Кратко: MCP и код 1С |

В репозиторий **не** кладём `mcp.json`, пароли, выгрузки конфигурации и копии ИБ.
