Как я подключаюсь к 1С и пишу код

Да — через MCP (MCP:RSV Data). Это не OData и не COM. MCP только читает базу; код модулей я пишу в файл на диске.

От агента отдельно: файл .bsl на диск. В HTTP 1С этот код не уходит.

В базе стоит расширение RSVData 1.3.0. Инструменты: config, describe, get_structure, query, execute_query (язык запросов 1С), reveal. Проведение документов и правка модулей конфигурации недоступны.

MCP — для этой работы

Уже настроен в Cursor (user-rsv-data), расширение в ИБ активно. Агент вызывает инструменты по схеме, без ручной сборки URL.

Цепочка: describe → Документ.ФУ_ЗаявкаНаОплату → get_structure → query по ГрафикПлатежей → процедуры на языке 1С.

OData — для интеграций

Публикация HTTP 1С для Excel, Power BI, сайта. Нужны IIS/Apache, пользователь, права. Для разбора метаданных агенту неудобнее и обычно шире открыт, чем нужно.
