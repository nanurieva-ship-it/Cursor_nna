# Как собрать расширение формы внутреннего документа

Файл для модуля расширения: `do/Forms/ВнутреннийДокумент/РасширениеФормы.bsl`.

## Что было не так в текущем модуле

1. **`&Вместо("ПередЗаписью")` без `ПродолжитьВызов`** — скопирован весь типовой `ПередЗаписью`. Он устаревает и ломает обновления.  
   Плюс **`&После("ПередЗаписью")` для плановой не вызывается**: при `&Вместо` типовой метод сам не идёт, `&После` на него не вешается.

2. **`_ПриСозданииНаСервере`** — ещё одна полная копия формы, аннотация `&Вместо` закомментирована. Процедура мертвая, а правки в ней не работают.

3. **`&Вместо("ПриЗаписиНаСервере")`** — снова копия типового. Нужен `&После` только на связи договора.

4. **Модуль `CheckLimitsDO` вставлен в форму ДО.** Это HTTP-сервис БП. В форме он не компилируется как сервис и только путает.

5. Кнопка **«Отправить на согласование»** — это переименованный `Зарегистрировать` (`ак_ПриСозданииНаСервереПеред`). Лимит плановой надо ловить в `&Вместо("ПередЗаписью")` **до** `ПродолжитьВызов`, при отказе оставлять `Зарегистрировать` доступной.

## Как заменить

В конфигураторе в модуле расширения формы:

- Удалить `_ПриСозданииНаСервере`, полный `_ПередЗаписью`, полный `_ПриЗаписиНаСервере`, вставленный `ПроверкаЛимитов` / `СтрокаОтветаЛимитаПоСтатье`.
- Оставить ваши `ВыгрузитьСчетВБП` и функции файлов (`ПолучитьПрисоединенныеФайлы`, `МоиДанныеФайла`…) — новый модуль их вызывает по имени.
- Вставить целиком `РасширениеФормы.bsl`.
- Доп. реквизит:

```
&Вместо("Подключаемый_ПриИзмененииДополнительногоРеквизита")
```

с `ПродолжитьВызов(Элемент)`, затем ваш `ПриИзмененииДокОплаты`.

В `ПараметрыПодключенияКБП` поставьте тот же пароль, что в `ВыгрузитьСчетВБП` (лучше константа, не два раза в коде).
