# Куда вставлять код (два разных модуля)

Код HTTP-сервиса (`Функция ЗагрузкаСтатусаStatus`) **нельзя** вставлять в форму внутренних документов. В форме нет `HTTPСервисОтвет` как обработчика URL, лимит и «Отправить на согласование» из‑за этого не работают.

## 1. Форма документа — только это

| Файл | Куда в конфигураторе |
|------|----------------------|
| `do/FormExtension.bsl` | Расширение САХ → `Справочник.ВнутренниеДокументы` → форма `ФормаЭлемента` → **модуль формы** |
| `do/Catalogs/ВнутренниеДокументы/МодульОбъекта.bsl` | Расширение САХ → `Справочник.ВнутренниеДокументы` → **модуль объекта** (пустой получатель плановой) |

Перед вставкой в модуле формы **удалите** всё с именами:

- `ЗагрузкаСтатусаStatus`
- `ЗагрузкаСтатусаPlanStatus`
- `ОбработатьСтатусПлановойЗаявки`
- `ОтветJSON` / `HTTPСервисОтвет`

Оставьте (или вставьте целиком) `FormExtension.bsl`: там `&Перед` / `&Вместо` записи, срок, лимит, `ОтправитьНаСогласованиеВБП`. Назначение читается и пишется только в `Объект.Назначение` (реквизит расширения), не в доп.реквизит.

## 2. Приём статуса из БП — только это

| Файл | Куда в конфигураторе |
|------|----------------------|
| `do/FromBuhStatus.bsl` | **HTTP-сервисы** → `ФУ_ЗагрузкаСтатусовИзБух` → **модуль сервиса** (не форма!) |

Шаблоны URL в том же сервисе:

- `DownloadStatus` → метод POST → обработчик `ЗагрузкаСтатусаStatus`
- `DownloadPlanStatus` → метод POST → обработчик `ЗагрузкаСтатусаPlanStatus`

Вставленный вами текст `ЗагрузкаСтатусаStatus` + `ОбработатьСтатусПлановойЗаявки` — это как раз этот модуль. Он уже полный. В форму его не копировать.

## 3. БП

| Файл | Куда |
|------|------|
| `bp/HTTPServices/ImportFromDO/Module.bsl` | HTTP-сервис `ImportFromDO`, метод `Download`. Правило 5% — сумма **всех** счетов плановой |
| `bp/Forms/Заявка/ОтправкаСтатусаВДО.bsl` | Форма заявки: удалить старый блок ак_*, вставить один раз |
| `bp/Forms/Заявка/строка-720.bsl` | В типовой `СоздатьПлатежноеПоручениеНаСервере` заменить `РеквизитФормыВЗначение` на `ДанныеФормыВЗначение` — иначе ошибка версии на строке 720 |
| `bp/Documents/ЗаявкаНаОплату/ПриЗаписи.bsl` | **Только объект** `ФУ_ЗаявкаНаОплату`. Реквизиты через `ЭтотОбъект["..."]`. В форму не вставлять: у формы другие параметры записи, ImportFromDO форму не открывает |
| `bp/Documents/ЗаявкаНаОплату/реквизиты.md` | Живые реквизиты заявки: `Тема`, `Назначение`, в графике `Статус` / `СуммаКОплате` |

## Как отличить

- Есть `&НаКлиенте` / `&Вместо("ПередЗаписью")` → форма.
- Есть `Функция ЗагрузкаСтатусаStatus(Запрос)` и `Новый HTTPСервисОтвет` → HTTP-сервис.
