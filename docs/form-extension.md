# Как собрать расширение формы внутреннего документа

Файл для модуля расширения (открывать без кириллицы): `do/FormExtension.bsl`.

## Что было не так в текущем модуле

1. **`&Вместо("ПередЗаписью")` без `ПродолжитьВызов`** — скопирован весь типовой `ПередЗаписью`. Он устаревает и ломает обновления.  
   Плюс **`&После("ПередЗаписью")` для плановой не вызывается**: при `&Вместо` типовой метод сам не идёт, `&После` на него не вешается.

2. **`_ПриСозданииНаСервере`** — ещё одна полная копия формы, аннотация `&Вместо` закомментирована. Процедура мертвая, а правки в ней не работают.

3. **`&Вместо("ПриЗаписиНаСервере")`** — снова копия типового. Нужен `&После` только на связи договора.

4. **Модуль `CheckLimitsDO` вставлен в форму ДО.** Это HTTP-сервис БП. В форме он не компилируется как сервис и только путает.

5. Кнопка **«Отправить на согласование»** — это переименованный `Зарегистрировать` (`ак_ПриСозданииНаСервереПеред`). Лимит плановой надо ловить в `&Вместо("ПередЗаписью")` **до** `ПродолжитьВызов`, при отказе оставлять `Зарегистрировать` доступной.

## Как заменить

В конфигураторе в модуле расширения формы:

- Удалить `_ПриСозданииНаСервере`, полный `_ПередЗаписью`, полный `_ПриЗаписиНаСервере`, вставленный `ПроверкаЛимитов` / `СтрокаОтветаЛимитаПоСтатье`.
- Оставить ваши `ВыгрузитьСчетВБП` и функции файлов (`ПолучитьПрисоединенныеФайлы`, `МоиДанныеФайла`…) — новый модуль их вызывает по имени.
- Вставить целиком `РасширениеФормы.bsl`.
- Доп. реквизит:

```
&Вместо("Подключаемый_ПриИзмененииДополнительногоРеквизита")
```

с `ПродолжитьВызов(Элемент)`, затем ваш `ПриИзмененииДокОплаты`.

В `ПараметрыПодключенияКБП` поставьте тот же пароль, что был в `ВыгрузитьСчетВБП` (лучше константа).

## Запись и согласование

Одна проверка `ПроверитьЛимитДокументаВДО` перед записью счёта и плановой заявки. Остаток 0 или минус — нет лимита. Плановая пишется всегда, счёт — только при лимите или `СверхЛимит`. Остаток по статье показывается **всегда**, не только при превышении.

Одна отправка `ОтправитьНаСогласованиеВБП` — `&Вместо("Зарегистрировать")` после типовой регистрации и отдельная кнопка `ак_ОтправитьНаСогласование`. При регистрации лимит повторно не проверяется: только «Ваша заявка отправлена на согласование».

Счёт из плановой заявки: если основание ещё не в состоянии **Согласован**, форму не открываем и запись не пускаем. Автоодобрение в БП — по **сумме всех счетов** этой плановой, не больше плановой × 1,05. Оплата заявки в БП (`Оплачена` / `Исполнен`) переносит в ДО состояние **Исполнен**.

Плановая: нет срока — отказ на клиенте и в `ПриЗаписиНаСервере`. Текст назначения — реквизит объекта **Назначение** из расширения (не доп.реквизит «Назначение платежа»). Счёт наследует его из плановой. Отмена документа финдиром в БП ставит в ДО **Не согласовано**. Остаток по статье — диалог **до** записи, затем запись продолжается. Счёт без лимита не пишется.

Не вставляйте старый `РегистрацияИОтправкаВБП.bsl` — он дублирует обработчики.
